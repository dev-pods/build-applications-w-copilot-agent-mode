👋 Boas-vindas à criação de uma aplicação multicamadas moderna com o modo Agent do GitHub Copilot!

Você criará o OctoFit Tracker usando:
- Camada de apresentação: React 19
- Camada de lógica: Node.js + Express + TypeScript
- Camada de dados: MongoDB

Portas usadas neste exercício:
- 5173 (privada, o Vite encaminha /api para a API)
- 8000 (privada, API sem autenticação)
- 27017 (privada)

📃 Documentação do GitHub Copilot: https://docs.github.com/pt/copilot
